Games

I have created a few projects in Unity, including one I published on itch.io (screenshot below).

This game is reminiscent of an arcade game and required me to do things like saving data between game sessions and working with prefabs and multiple scenes.

I added in some simple sound effects every time the player scored a point to create a more engaging experience for the player and to give them feedback when they achieve something.

When I got feedback about the game I was told that after a while it got a bit repetitive. To address this I added an extra game mode that includes gameplay variations as the players score got higher.

Art

I enjoy creating art in photoshop. Most of my art is based on video games I enjoy like ‘Resident Evil’ or ‘Hollow Knight’.

I like to experiment with different art styles in my art pieces to improve my skills. I mainly draw characters at the moment but I want to try creating more landscapes for practice. I also want to experiment with creating more realistic pictures and also creating some original designs.

While working with photoshop I have learnt some simple techniques to blend colours into each other and also how to blur backgrounds.

These are just some of my artwork, most of them are posted on my instagram account.

Maya

I have created objects using Maya. These included a dice, campfire and a signpost. My inspiration behind these objects were tabletop D&D.

Each object required a number of skills such as extruding faces and inserting edge loops.

I textured the objects using lamberts and blinns. For example, the faces of the dice are using a translucent lambert and the divots are a blinn.

For each object I created a three point lighting setup using Arnold lights in maya.

I also created animations for each one and exported them to create an mp4 video file.
